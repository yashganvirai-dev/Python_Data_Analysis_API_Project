# Python Data Analysis & API Application

## Day 16–20 Internship Project

This project demonstrates Python data analysis, data cleaning, visualization, REST API consumption, JSON processing, and automated report generation.

### Technologies
- Python
- NumPy
- Pandas
- Matplotlib
- Seaborn
- Requests
- JSON

### Project Features
1. Load sales data using Pandas.
2. Check and clean missing values.
3. Remove duplicate records.
4. Calculate total revenue, quantity sold, and average rating.
5. Analyze sales by product and category.
6. Create charts using Matplotlib and Seaborn.
7. Consume a REST API using Requests.
8. Process JSON API data.
9. Convert API response to a Pandas DataFrame.
10. Generate a text-based final report.

### Files
- `sales_data.csv` — project dataset
- `data_analysis_project.py` — complete project code
- `requirements.txt` — required Python libraries
- `final_report.txt` — generated analysis report

### How to Run
```bash
pip install -r requirements.txt
python data_analysis_project.py
```

### Google Colab
Upload `sales_data.csv` to the Colab notebook before running the analysis cells.
